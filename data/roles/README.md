# Roles review

`todo/batch_NNN.json` – cases generated by `scraper/05_relevance.py`: theory summary + top candidate
entities (`[id, title, type, short description, "L" if in lead + mention count]`).

`done/batch_NNN.json` – reviewed result, one object per theory:

```json
{
  "Q815614": {
    "status": "confirmed",
    "roles": { "Q35794": "acc", "Q17": "loc" }
  }
}
```

## Status (based on the Wikipedia article's consensus, not opinion)

| code | meaning |
|---|---|
| `confirmed` | documented / proven (e.g. MKUltra, COINTELPRO) |
| `debunked` | rejected by evidence / scholarly consensus |
| `disputed` | unproven, contested or partially true |

## Roles

| code | LT | meaning |
|---|---|---|
| `acc` | Kaltinamas | alleged perpetrator / who supposedly conspires |
| `pro` | Skleidėjas | promoter, proponent, popularizer |
| `vic` | Auka / taikinys | victim of the alleged plot or target of the theory's harassment |
| `sub` | Objektas | what the theory is about (substance, technology, object) |
| `evt` | Įvykis | event the theory explains or builds on |
| `loc` | Vieta | place central to the theory |
| `deb` | Paneigėjas / tyrėjas | debunker, investigator, official inquiry |
| `rel` | Susijusi teorija | closely related conspiracy theory |

Candidates not listed are considered incidental (kept only in the extended layer).
Only listed IDs may be used; new entities are not invented.
